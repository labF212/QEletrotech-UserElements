# ⚙️ QEletrotech-UserElements

**Desenho de modelos de equipamentos personalizados para o QElectroTech**, que não estão presentes na biblioteca padrão do software.

![Exemplo de elementos personalizados](https://github.com/labF212/QEletrotech-UserElements/blob/main/Screenshot_20250430_155403.png)

## 📁 Como adicionar novos elementos

1. No QElectroTech, vá até ao menu **Colecções**.
2. Escolha **Colecção do Utilizador**.
3. Clique em **Abrir a pasta correspondente**.

Essa pasta contém os elementos personalizados — são basicamente ficheiros de desenho (`.elmt`) organizados em pastas.

### ➕ Adicionando novos elementos

- Copie os ficheiros e pastas desejados para essa pasta da "Colecção do Utilizador".
- Ao reiniciar o QElectroTech, os novos elementos estarão disponíveis.

### 📝 Personalização

#### Nome e ordem dos elementos

- Para alterar a **ordem de exibição** das pastas, renomeie-as com um prefixo numérico:
  - Exemplo: `30_Arduino` → aparecerá como *Arduino*, na terceira posição da lista.

#### Tradução dos nomes

- Para **editar os nomes visíveis** (e traduzir, se necessário), edite o ficheiro `qet-directory`.
  - Este ficheiro permite definir os nomes apresentados na interface do QElectroTech.

# ⚙️ QEletrotech-UserElements (English)

**Design of custom equipment models for QElectroTech**, not included in the software’s default library.

![Example of custom elements](https://github.com/labF212/QEletrotech-UserElements/blob/main/Screenshot_20250430_155403.png)

## 📁 How to add new elements

1. In QElectroTech, go to the **Collections** menu.
2. Choose **User Collection**.
3. Click **Open the corresponding folder**.

This folder contains custom elements — essentially drawing files (`.elmt`) organized in directories.

### ➕ Adding new elements

- Copy the desired files and folders into this "User Collection" folder.
- After restarting QElectroTech, the new elements will be available.

### 📝 Customization

#### Name and order of elements

- To change the **display order** of folders, rename them with a numerical prefix:
  - Example: `30_Arduino` → will appear as *Arduino*, in the third position.

#### Name translation

- To **edit the displayed names** (and translate them if needed), edit the `qet-directory` file.
  - This file allows you to define how names are shown in the QElectroTech interface.
